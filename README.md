# Stardust Florals™ — Trandafiri cu Sclipici & Aranjamente Virale

Website e-commerce de conversie mare pentru comercializarea buchetelor de trandafiri cu sclipici și luminițe LED (produs viral TikTok), cu opțiune unică de felicitare cu cod QR video personalizat și selecție rapidă a culorilor.

## Cum rulezi proiectul
- **Vizualizare Imediată:** Fă dublu-click pe `index.html` pentru a deschide site-ul în browser.
- **Hosting Live:** Încarcă fișierele (`index.html`, `styles.css`, `app.js`) pe Cloudflare Pages sau Vercel.
- **Next.js:** Fișierul `page.tsx` este disponibil pentru utilizare în Next.js.
